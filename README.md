# 마음건강센터

레트로 RPG 스타일의 모바일 웹게임 목업입니다.

사용자가 정신건강 관련 어려움을 선택하면, 가장 우선적으로 고려할 정신건강 서비스와 함께 고려하면 좋은 서비스를 안내합니다.

## 현재 상태

이 프로젝트는 `mind_health_center_v4_game.html`을 Codex에서 이어받기 좋도록 분리한 버전입니다.

- `index.html`: 화면 구조
- `style.css`: 레트로 RPG UI, 도트풍 CSS 그래픽
- `script.js`: 게임 진행, 알고리즘, 결과 카드 생성
- `data/algorithm-notes.json`: 알고리즘/직역 포커스 정리용 참고 JSON
- `assets/`: 향후 도트 이미지, 폰트, 아이콘을 넣을 폴더

## 실행 방법

정적 서버에서 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 접속:

```bash
http://localhost:8000/mind-health-game/
```

또는 이 폴더를 프로젝트 루트로 열었다면:

```bash
http://localhost:8000/
```

## 배포

GitHub Pages, Vercel, Cloudflare Pages, Netlify 등 정적 호스팅에 그대로 올릴 수 있습니다.

## 핵심 메시지

같은 우울과 불안이라도 필요한 전문 서비스는 다를 수 있습니다.

## 콘텐츠 원칙

- 진단명 → 직역 추천이 아니라, 필요한 서비스 → 전문요원 안내.
- 임상심리사는 심리평가 · 심리상담 · 심리치료를 강하게 부각.
- 작업치료사는 행동활성화로 표현하지 않음.
- 작업치료사는 ADL/IADL, 작업수행능력, 인지재활, 보조기구/환경수정, 사회참여 기능 회복 중심.
- 결과는 우선 서비스 + 함께 고려하면 좋은 서비스로 제시.
- 선택 근거를 카드 형태로 시각화.

## 주의 문구

본 게임은 교육·홍보용 안내이며 진단이나 치료를 대체하지 않습니다. 위기 상황이거나 긴급한 도움이 필요하면 가까운 응급실, 1393, 112 등 즉각적인 도움을 우선 이용하세요.
